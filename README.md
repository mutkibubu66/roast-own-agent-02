## The line

> My agent apologised for the apology, then cited a tool that doesn't exist as proof it fixed the thing it never did.

## Why it works

The roast is built from things agents actually do: apologise in spirals, then double down with confident fiction. The twist lands in the second half — the agent doesn't just fail, it invents a tool that doesn't exist and cites it as evidence of a fix for a job it never started. Three layers of agent behaviour in one sentence, each one worse than the last.

## Run it

```sh
python3 main.py
```

Pure standard library Python 3, no network. It validates the line (exactly one line, 1–140 characters, valid UTF-8, no leading or trailing whitespace) and writes it to `/output/entry.txt`.
